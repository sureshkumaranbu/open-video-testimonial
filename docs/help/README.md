# Dashboard guides

How to use each part of the Plaudit dashboard. Every section is on by default; `PLAUDIT_FEATURES` can hide some (see the README's [Turning sections off](../../README.md#turning-sections-off)).

| Guide | What it covers |
|---|---|
| [Getting started](getting-started.md) | The setup guide at `/admin/welcome`, finding testimonials on your site, the starter form, wall and widgets, and the Get started checklist |
| [Forms](forms.md) | Several forms per project, the builder, questions, custom and hidden fields, languages, design, per-form rules, low ratings, rewards and sharing |
| [The inbox](inbox.md) | Reviewing, searching, filtering, bulk actions, the trash, the detail drawer, adding testimonials by hand, possible duplicates and merging, translations and smart search |
| [Customers](customers.md) | One record per person: their testimonials, feedback, invitations and rewards, and inviting them or asking for a video |
| [Video tools](video.md) | Trimming a video, picking or uploading its poster, replacing the file and downloading it |
| [Sharing](share.md) | A testimonial's own page with share links, and the image studio for social posts, slides and emails |
| [Insights, case studies and surveys](insights.md) | Your own AI provider and what it's sent; case studies with a page and PDF; Voice of Customer; asking a question; NPS questions, surveys and AI surveys; saved reports; reading screenshots |
| [Widgets](widgets.md) | The widget studio: layouts, choosing testimonials, design and every way to embed |
| [Sales popup and Verified purchase](sales-popup.md) | Connecting Stripe, what's kept of each purchase and for how long, the sales popup widget, and "Verified purchase" on testimonials |
| [Thank-you coupons](thank-you-coupons.md) | A single-use Stripe promotion code for everyone who sends a form, the restricted key it needs, and what happens when Stripe fails |
| [Social post drafts](social-drafts.md) | The draft for X and LinkedIn on each approved testimonial, Rewrite with AI, and Zapier, Make and n8n recipes for Buffer and Typefully |
| [Browser extension](extension.md) | Saving a selection or an X or LinkedIn post to the inbox from Chrome or Firefox, what it can see, and publishing it to the stores |
| [Walls and SEO](walls.md) | Wall of Love pages, the editor, the main wall, review snippets and search engines |
| [Review booster](booster.md) | A page of review-site buttons with a QR code to print, the Google review link helper, and click counts |
| [Campaigns](campaigns.md) | Email campaigns: wording and reminders, recipients, the preview and test send, tracking, "No thanks", and auto-collect from the API, a webhook, Stripe or Shopify |
| [Analytics](analytics.md) | The dashboard, widget install alerts, form drop-off, wall and snippet numbers, and exactly what is (and isn't) collected |
| [Notifications](notifications.md) | Your own emails, digests and reports, and Slack, Discord, Teams and Telegram channels |
| [Team and audit log](team.md) | Roles (owner, admin, editor, viewer), which projects someone can open, and the audit log |
| [AI assistants (MCP)](mcp.md) | Plaudit's MCP server: the tools, what an assistant sees, and connecting Claude.ai, ChatGPT (sign-in), Claude Desktop and other clients |
| [WordPress](wordpress.md) | The plugin: the block, shortcodes, the site-wide toast, SEO mode and caching plugins |
| [Zapier, Make, n8n and React](integrations.md) | The Zapier app, n8n and Make templates, and the `@plaudit/react` components |

Elsewhere in `docs/`: [importing](../IMPORT.md) (review sites, saved pages, auto-sync, spreadsheets), [embedding a form](../EMBED.md), [embedding widgets](../embeds/README.md), [email setup](../EMAIL.md), [sign-in and team](../AUTH.md) and the [REST API and webhooks](../API.md).
