# Plaudit widget on Notion

Get the snippet from **Widgets › your widget › Share** in the dashboard. Replace `https://plaudit.example` and `w_abc123def456` below with your own server and widget id.

Notion doesn't run scripts, so use the hosted link:

1. Copy the **Hosted link** from the Share tab (`https://plaudit.example/embed/w_abc123def456`).
2. In Notion, type `/embed` and paste the link.
3. Resize the embed to fit.
