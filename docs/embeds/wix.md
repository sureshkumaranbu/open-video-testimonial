# Plaudit widget on Wix

Get the snippet from **Widgets › your widget › Share** in the dashboard. Replace `https://plaudit.example` and `w_abc123def456` below with your own server and widget id.

1. Choose **Add › Embed code › Embed HTML**.
2. Pick **Code** and paste the iframe snippet from the Share tab (Wix shows custom code inside a frame anyway).
3. Drag the frame to the size you want and publish.
