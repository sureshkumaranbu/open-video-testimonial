# Embedding a saved widget

Step-by-step guides: [WordPress](wordpress.md), [Webflow](webflow.md), [Framer](framer.md), [Wix](wix.md), [Squarespace](squarespace.md), [Shopify](shopify.md), [Ghost](ghost.md), [Notion](notion.md), [Next.js](nextjs.md), [React component](react.md).

Every widget can go on a page four ways (all on the **Share** tab): the script (recommended), an iframe that grows to fit, a hosted link (`/embed/w_…`), and a server-side HTML include for search engines. See [EMBED.md](../EMBED.md) for every option.
